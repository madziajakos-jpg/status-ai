# Status AI

Aplikacja na telefon: status ChatGPT, Gemini, Groka i Grok Bota, z oficjalnych stron.

Otwórz na telefonie: **https://madziajakos-jpg.github.io/status-ai/**

Potem w przeglądarce: **Dodaj do ekranu głównego** (w Safari: Udostępnij → Dodaj do ekranu początkowego; w Chrome: menu → Dodaj do ekranu głównego).

## Powiadomienia

1. Zainstaluj darmową aplikację **ntfy** (Google Play albo App Store).
2. Dodaj subskrypcję tematu: `status-ai-magda-7bopyo19lm`
3. Powiadomienie przychodzi tylko wtedy, gdy status którejś usługi się zmieni.

Ikony w aplikacji są autorskie (nie używamy oficjalnych logotypów). Nazwy usług są podpisane tekstem.
